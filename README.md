# Fliegengitter Fenster

Premium Insektenschutzlösungen aus Österreich für Ihr Zuhause.

## 🚀 Features

- Maßgefertigte Fliegengitter für Fenster und Türen
- Hochwertige Materialien: Aluminium, Fiberglas, Edelstahl
- Professionelle Montage in ganz Europa
- Mehrsprachige Unterstützung (Deutsch, Türkisch)
- Responsive Design für alle Geräte

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS v3
- **Language**: TypeScript
- **Font**: Inter (Google Fonts)

## 📦 Installation

```bash
npm install
npm run dev
```
